MORERENT

A Nigerian property rental and marketplace platform.

MORERENT helps people discover rental properties and properties for sale, connect with landlords and agents, and access participating stores.

Project Status

MORERENT V1 is deployed on Netlify and is under development.

Live Application

https://morerent-app.netlify.app/

Main Features

- Browse approved property listings.
- Register as a customer, landlord, agent, or store owner.
- Submit property listings for administrator approval.
- Subscribe to landlords, agents, and stores.
- Submit house requests.
- Store owners can manage products for their subscribers.
- Administrative tools for approvals and platform management.

Technology

- HTML
- CSS
- JavaScript
- Supabase
- Netlify

Developer Instructions

Please review the existing implementation before making changes. Preserve working features, coordinate with other contributors, and document significant changes.

Pay particular attention to:

- Supabase Row Level Security (RLS) and database policies.
- Authentication and role permissions.
- Admin access and property approvals.
- Subscriptions and house requests.
- Frontend and backend integration.
- Protection of private information and credentials.

Security: Never commit service-role keys, secret API keys, database passwords, or other private credentials to this public repository.
